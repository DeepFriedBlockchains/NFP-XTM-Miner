# XTM-MINER privacy

Pool credentials remain encrypted through Android Keystore. Pool profiles, tuning, logs and session data remain on the device. Mining contacts the configured pool endpoints with the user's payout address and optional worker. All app developer mining rotation is removed. Upstream installation telemetry, cloud accounts, remote control and APK update connections are disabled in every fork build. The original source retains disabled compatibility classes, but their shared HTTP transport rejects requests. Android foreground mining remains visible to the device owner. No private keys or wallet recovery phrases are required.
